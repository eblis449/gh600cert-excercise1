## Recent GitHub Changelog highlights (github.blog/changelog)

- **Refreshed repository pull requests page (public preview)** — a redesigned repo-level Pull Requests list, directly useful for teaching PR and collaboration basics.
- **Configure cost and quality in Copilot auto model selection** — tune how Copilot's automatic model selection balances cost versus output quality.
- **Auto-resolution and analysis updates in Copilot code review** — Copilot code review can now auto-resolve certain comments with improved analysis.
