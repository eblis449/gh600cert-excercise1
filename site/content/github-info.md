## Recent GitHub Changelog highlights (github.blog/changelog)

- **Private saved views for repository issues, generally available** — save and reuse custom issue filters/views per repository, plus a new "Relates to" issue relationship for linking related work.
- **Changes to query results in the GitHub Actions API and UI** — workflow run queries now return updated result sets; useful for teams scripting Actions dashboards.
- **Agentic autofix now uses Copilot Memory** — Copilot's automated code-scanning fixes retain more context across a repository, improving fix relevance.
- **More ways to request and configure Copilot code reviews** — additional entry points and settings for triggering Copilot as a reviewer on pull requests.
- **Require proof of presence for high-impact actions** — a new security control that adds verification steps before sensitive account or org actions can be taken.
- **Node 20 is no longer available in GitHub Actions** — workflows still pinned to Node 20 runners should upgrade to a supported version.
- **CodeQL 2.27.1** adds C/C++ query improvements and Kotlin 2.4.20 support for code scanning.
- **Claude Opus 5.5 and OpenAI's GPT-6 (Sol and Luna)** are now available as model choices in GitHub Copilot.
