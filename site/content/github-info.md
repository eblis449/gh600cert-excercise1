# GitHub Info

## Mona's editorial angle

Mona's website focuses on practical GitHub guidance backed by official references from:

- docs.github.com
- github.blog
- github.blog/changelog

## Current homepage themes

- GitHub collaboration basics: repositories, branches, pull requests, and merges.
- GitHub Copilot as an AI coding assistant across the IDE, CLI, and GitHub.
- GitHub Actions as the automation layer behind repository workflows.
- Recent GitHub Blog and Changelog stories worth watching.

## Recent GitHub Blog highlights (github.blog/latest)

- **GitHub Copilot app for Beginners** is an ongoing series covering practical Copilot app workflows: building custom workflows with canvases, using the diff/terminal/browser, running several agents at once, and automating Dependabot pull request triage.
- **Migrating the GitHub Copilot runtime to Rust, using Copilot** — an inside look at how the Copilot team used Copilot itself to modernize its own runtime.
- **How we make AI coding more cost efficient without sacrificing task quality** and **How to evaluate LLMs before production** — practical guidance for teams adopting AI coding tools responsibly.
- **Decoding the new AI lingo: Loops, harnesses, squads, hill climbing… oh my!** — a glossary-style explainer for developers new to agentic AI terminology, good beginner-friendly linking material.

## Recent GitHub Changelog highlights (github.blog/changelog)

- **Copilot code review: An improved review experience** and **Agentic autofix now uses Copilot Memory** — Copilot's code review and autofix capabilities keep expanding.
- New models available in GitHub Copilot: **Claude Opus 5.5**, **OpenAI's GPT-6 (Sol and Luna)**, and **Grok 4.7** — useful for a "which model to pick" comparison post.
- **Local sandboxing** and **OpenTelemetry support** landed in the GitHub Copilot app, plus faster C++ code intelligence via whole-codebase indexing.
- **Refreshed repository pull requests page** is now generally available — worth a screenshot-driven walkthrough for the PR basics content.
- GitHub Actions: **Node 20 is no longer available** (retired) and artifact/query result behavior changed — flag these as breaking changes for workflow authors.
- **GitHub Copilot weekly releases** posts continue on a regular cadence — good recurring source for "what's new this week" recaps.
