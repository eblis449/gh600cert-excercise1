## Recent GitHub Changelog highlights (source: github.blog/changelog)

- **Refreshed repository pull requests page is generally available** — the new pull requests page makes it easier to find and act on PRs across a repository. Rolling out to all users.
- **Security improvements for SSH** — GitHub is removing several legacy SSH algorithms, adding a new algorithm, and requiring larger RSA key sizes to strengthen Git-over-SSH security.
- **Faster C++ code intelligence in GitHub Copilot CLI** — whole codebase indexing speeds up code intelligence for large, deeply interconnected C++ repositories.
- **New Copilot for JetBrains features** — version 1.18.0 adds AI-assisted tool approvals, more control over agent conversations, and shared team skills/instructions.
- **New model availability in GitHub Copilot** — Claude Opus 4.5 and additional OpenAI GPT-5 model variants have been added as selectable models for agentic coding tasks.
