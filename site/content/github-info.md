## Recent GitHub Copilot & Actions updates

A quick roundup of practical, developer-facing news, pulled from github.blog and github.blog/changelog:

- **Copilot code review gets an improved review experience** — clearer tracking of review changes, smarter auto-resolve, and auto-generated commit messages when suggestions are accepted. (Source: github.blog/changelog)
- **Weekly Copilot releases** continue to ship incremental updates, including model selection changes, code review improvements, and a Sentry integration in the Copilot app. (Source: github.blog/changelog)
- **Some Copilot models are being deprecated in mid-October 2026** across chat, inline, agent, and completion surfaces — worth a heads-up for teams standardizing on specific models. (Source: github.blog/changelog)
- **Copilot impact dashboard** now shows per-feature engagement, helping enterprise admins see which Copilot features teams actually use. (Source: github.blog/changelog)
- **Agentic CLI customizations** (skills, custom agents, MCP servers, slash commands, plugins) are now visible in the Copilot usage metrics API, useful for tracking CLI adoption. (Source: github.blog/changelog)
- **Ubuntu 26 is now GA** for GitHub Actions runner images (x64/arm64) — a good prompt to plan runner image migrations. (Source: github.blog/changelog)
- **Code coverage ruleset condition** can now be managed via the REST API, making it easier to automate repository rule enforcement. (Source: github.blog/changelog)
- **Migrating the Copilot runtime to Rust, using Copilot itself** — a behind-the-scenes look at how GitHub used Copilot agents to port an ~800K-line runtime, showing Copilot's growing role in large-scale engineering work. (Source: github.blog)
