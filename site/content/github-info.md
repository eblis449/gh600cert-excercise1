## Recent GitHub Changelog highlights

- [Control GitHub Actions cache access with cache-mode](https://github.blog/changelog/2026-09-10-control-github-actions-cache-access-with-cache-mode) — new setting to restrict which workflows can read/write the Actions cache, a good Actions-security callout.
- [Refreshed repository pull requests page in public preview](https://github.blog/changelog/2026-09-10-refreshed-repository-pull-requests-page-in-public-preview) — updated PR list view for repositories.
- [Block pull requests with exposed secrets from merging](https://github.blog/changelog/2026-09-09-block-pull-requests-with-exposed-secrets-from-merging) — secret scanning now blocks merges when secrets are detected in a PR.
- [Enforce GitHub Advanced Security configurations](https://github.blog/changelog/2026-09-15-enforce-github-advanced-security-configurations) — org admins can enforce security configs across repositories.
- [Copilot budget increase requests are generally available](https://github.blog/changelog/2026-09-16-copilot-budget-increase-requests-are-generally-available) — Copilot admins can now request budget increases directly.
