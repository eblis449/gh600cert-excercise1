## Recent GitHub Changelog highlights (source: github.blog/changelog)

- **Refreshed repository pull requests page** in public preview — updated collaboration UI for browsing PRs.
- **AI Scan for pull request APIs** in public preview — adds automated security scanning to PR-related APIs.
- **Copilot code review can now approve pull requests** — Copilot's review agent can approve PRs directly, not just comment.
- **Enterprise managed permissions for GitHub Copilot agent operations** — admins get finer-grained control over what Copilot agents can do.

- **Block pull requests with exposed secrets from merging** — an added safeguard for secret scanning.
