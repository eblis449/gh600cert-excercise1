## Recent GitHub Changelog highlights

- **CodeQL 2.27.1** adds C/C++ query and Kotlin 2.4.20 support (Improvement, Sep 25).
- **Require proof of presence for high-impact actions** — new security control for sensitive account/repo actions (Release, Sep 24).
- **Node 20 retired from GitHub Actions** — action authors should move workflows to a supported Node version (Retired, Sep 23).
- **Claude Opus 5.5** and **OpenAI's GPT-6 Sol / GPT-6 Luna** are now available in GitHub Copilot, alongside **Grok 4.7** (Release, Sep 21–22).
- **Faster C++ code intelligence with whole codebase indexing** — improved navigation and completions for large C++ projects (Release, Sep 22).
- **Refreshed repository pull requests page** is now generally available (Release, Sep 21).
- **Copilot code review: An improved review experience** — updates to how Copilot presents review feedback (Improvement, Sep 18).
- **Workflow execution protections in GitHub Actions** are now generally available, adding safeguards against risky workflow runs (Release, Sep 17).
- **Ubuntu 26** is now generally available as an Actions runner image, with migration guidance from older Ubuntu images (Improvement, Sep 17).
