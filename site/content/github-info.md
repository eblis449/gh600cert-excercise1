## Recent highlights worth featuring (as of September 2026)

From **github.blog/changelog**:

- **Refreshed repository pull requests page is generally available** — a redesigned PR list view is now the default, making it easier to scan and triage open pull requests. (GitHub Changelog)
- **More ways to request and configure Copilot code reviews** — repository owners can fine-tune when and how Copilot reviews pull requests. (GitHub Changelog)
- **Workflow execution protections in GitHub Actions are generally available** — helps teams lock down which workflows can run and reduces the risk of supply-chain style attacks in CI/CD. (GitHub Changelog)
- **Node 20 is no longer available in GitHub Actions** — teams still on Node 20 runners should upgrade their workflows to avoid breakage. (GitHub Changelog)
- **Automate SSO authorization for classic PATs and SSH keys** — reduces manual overhead for enterprises managing access tokens. (GitHub Changelog)
